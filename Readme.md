handout: This directory contains all the instructions
sample_input: Base cases (inputs) & (the output generated by assembly.py)
sample_output: Base cases (outputs)
assembler.py: implementation of assembler

Testing your code locally (in the top directory of):

$ python3 assembler.py sample_input/[INPUT_FILENAME.S]
$ diff sample_input/[INPUT_FILENAME.O] sample_output/[INPUT_FILENAME.O]

no output -> pass
any output -> fail 

DEBUG MODE = 1 for quick debugging
