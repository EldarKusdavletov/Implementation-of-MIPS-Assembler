<h2>Content of the repository</h2>
<i> handout: </i> This directory contains all the instructions <br/>
<i> sample_input: </i> Base cases (inputs) & (the output generated by assembly.py) <br/>
<i> sample_output: </i> Base cases (outputs) <br/>
<i> assembler.py: </i> implementation of assembler <br/>

<h2>Testing your code locally (in the top directory of):</h2>

<tt>python3 assembler.py sample_input/[INPUT_FILENAME.S]</tt><br/>
<tt>diff sample_input/[INPUT_FILENAME.O] sample_output/[INPUT_FILENAME.O]</tt><br/>

no output -> pass <br/>
any output -> fail <br/>

<strong> DEBUG MODE = 1 </strong> for quick debugging
